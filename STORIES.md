# User stories

1. Som läsare vill jag kunna se alla böcker i katalogen med titel och författare, samt kunna markera eller avmarkera en bok som favorit via hjärtat, för att hålla koll på vilka böcker jag kanske vill läsa.

2. Som läsare vill jag kunna lägga till en bok som saknas i katalogen, genom att skriva in titel och författare, för att kunna välja den som favorit.

3. Som läsare vill jag kunna se vilka böcker jag markerat som favoriter, i en lista för att enkelt hitta en bok att läsa härnäst.
